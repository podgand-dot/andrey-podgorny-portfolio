# Портфолио Андрея Подгорного

Статический сайт на HTML, CSS и JavaScript. Публичная часть размещается отдельно; формы управления контентом работают только в локальном режиме.

## Разделы

- Главная страница и краткое CV.
- Каталог проектных кейсов с отдельными страницами описания.
- Галерея сертификатов, наград и рекомендаций.
- Отдельная страница опыта работы и стажировок.
- Образование, лидерство и медиаматериалы.

## Данные

- `data/projects.json` — каталог проектов.
- `data/certificates.json` — сертификаты и их описания.
- `data/experience.json` — подтверждённые места работы и стажировки.
- `data/portfolio-data.js` — автоматически собираемый резерв для предпросмотра страниц напрямую из папки.
- `assets/cv/` — резюме и его превью.
- `assets/letters/` — благодарственные и рекомендательные письма.
- `assets/certificates/` — сертификаты и миниатюры.
- `assets/projects/<slug>/` — материалы каждого проекта в отдельной папке.
- `assets/profile/`, `assets/gallery/`, `assets/audio/` — портреты, фотографии и аудио.

Проекты, сертификаты и опыт работы хранятся отдельно. Показатели, рассчитанные в проектных моделях, следует маркировать как прогнозы или допущения.

## Локальная загрузка сертификатов

1. Установить Node.js. Дополнительные пакеты не нужны.
2. В папке сайта выполнить `npm start`.
3. Открыть `http://127.0.0.1:3000/admin`.
4. Загрузить PNG, JPG, WebP или PDF и заполнить описание. Запись и файл сохраняются в папку сайта.
5. После проверки обновлённую папку проекта нужно опубликовать штатным способом. Новые записи не сохраняются в браузере посетителя.

Локальный сервер привязан к `127.0.0.1`; панель и серверные файлы исключены из Vercel-выкладки через `.vercelignore`. Не открывайте локальный сервер для внешней сети.

## Запуск сайта локально

Для просмотра можно открыть `index.html` напрямую: проекты, сертификаты и опыт загрузятся из резервного набора данных. Либо выполнить `npm start`, который запускает сайт и панель управления сертификатами по адресу `http://127.0.0.1:3000`. Команда `npm run build` обновляет резервный набор после ручного редактирования JSON.

## Поддержка проекта

Изменяйте структурированные JSON-данные и соответствующие материалы в `assets/`. Не используйте старые черновики `legacy_backup` как текущий источник контента без сверки.
